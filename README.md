# Conway's Game of Life

A simple React + Vite implementation of Conway's Game of Life.

## Features

- Interactive cell grid with customizable evolution.
- Multiple color themes for light and dark modes.
- Ready-made preset patterns and saved pattern support.
- Responsive layout optimized for mobile screens.

## Setup

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Notes

- The project uses Vite's `base` configuration for GitHub Pages deployment.
- The app entry and asset paths are configured to work with that base path.
- Mobile screens have reduced padding for a tighter and more usable layout.
